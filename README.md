# PL BUNDLES — The Funhouse

A luxury, circus-themed website for **PL BUNDLES**, a hair bundle business in Baltimore, MD.

**Tagline:** Where Good Hair Is the Main Attraction.

## What it does

- Opens with a red velvet curtain animation (plays once per visit, can be skipped, and respects reduced-motion settings)
- Shows 3- and 4-bundle deals from 20″ to 30″, with every price kept in one central config
- Walks customers through a step-by-step bundle builder: texture → quantity → length → pickup or delivery → contact info → review
- Updates the price as the customer chooses, and takes the $15 pickup deposit off the total
- Shows delivery address fields only when delivery is chosen, with validation
- Has an editorial campaign gallery, a brand story, a How to Order section, policy accordions and a contact section
- Includes an owner dashboard for order requests, statuses, private notes, prices, texture availability and policies
- Works on phones first: one builder step at a time, a collapsible order summary and a sticky Shop button

## Built with

Plain HTML, CSS and JavaScript in a single page, with no framework or build step. Fonts are Abril Fatface, Bodoni Moda and Jost from Google Fonts.

## How ordering works on this version

Customers don't pay online. On this static version, the site writes out a submitted order request as a text message to the business number. The hosted version uses a database to save requests and show them in the owner dashboard.
